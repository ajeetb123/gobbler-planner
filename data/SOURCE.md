# Data provenance

Both files are VT University DataCommons (UDC) grade distribution exports, republished in public GitHub repos.
They are used here only for offline backtests. Production must download the official export from UDC directly.

- `udc_2019_2022.csv`: Fall 2019 to Spring 2022 (6 terms), from github.com/jrudman25/CourseSearch
- `udc_2022_2024.csv`: Fall 2022 to Spring 2024 (4 terms), from github.com/gsoni1/GradeDistVis

Columns: Academic Year, Term, Subject, Course No., Course Title, Instructor (last name only), GPA,
A (%) ... F (%), Withdraws, Graded Enrollment, CRN, Credits.
