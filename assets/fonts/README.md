# Fonts

Self-hosted so the site loads nothing from other servers. All are open fonts under the SIL Open Font License 1.1
(license texts alongside). Latin subset, variable weight, copied from the `@fontsource-variable/*` npm packages in Nov 2026.

- `urbanist.woff2`: headings
- `schibsted-grotesk.woff2`: body text
- `martian-mono.woff2`: course codes and small technical labels
