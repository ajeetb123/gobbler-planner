# Fonts

Self-hosted so the site loads nothing from other servers. All three are open fonts under the SIL Open Font License 1.1
(license texts alongside). Latin subset, variable weight, copied from the `@fontsource-variable/*` npm packages on Nov 21, 2026.

- `bricolage-grotesque.woff2`: headings
- `schibsted-grotesk.woff2`: body text
- `martian-mono.woff2`: course codes and small technical labels
